# EduControl 🎓

Sistema web de gestión y control educativo desarrollado con **Laravel 13**, creado como proyecto final para el curso de **Arquitectura y Programación Web**.

## 📋 Descripción del Proyecto
**EduControl** es una aplicación web diseñada para centralizar y optimizar los procesos administrativos y académicos dentro de una institución educativa, aplicando buenas prácticas de arquitectura de software, patrón MVC y desarrollo colaborativo.

## 🚀 Tecnologías Utilizadas
* **Backend:** PHP 8.x / Laravel 13
* **Frontend:** Blade, Tailwind CSS / Bootstrap, JavaScript
* **Base de Datos:** MySQL / MariaDB
* **Control de Versiones:** Git & GitHub
